### Install and update

**Windows:** extract the complete ZIP and run `Install_HYBRIDIR.cmd`. For normal use leave TI compilation disabled. Launch `Start_HYBRIDIR.cmd` from the installed folder. Before updating, close the app, use the same flavor/channel, and retain backups. These are ZIP setup packages, not signed EXE/MSI installers.

**macOS:** extract the matching ZIP with Archive Utility, drag `HYBRID IR.app` to Applications and open it. Python, Tcl/Tk and dependencies are included; no separate Python or Homebrew is needed. To update, quit the app, back up your data and replace the whole `.app`. Remove the `.app` to uninstall; personal data and settings remain.

**Mac security:** ad-hoc signed, not Developer ID signed and not notarized by Apple. If you trust and verify this download, follow the application-specific **System Settings → Privacy & Security → Open Anyway** route when offered. Do not globally disable Gatekeeper or bypass malware/damage warnings. Download/quarantine acceptance was not part of CI validation. [Apple guidance](https://support.apple.com/en-us/102445).

**[Full installation, updates, removal and troubleshooting guide](https://github.com/Leemuzhko/HYBRID-IR/blob/main/docs/en/installation.md)** — separate Windows and macOS sections, checksum commands and user-data paths. ### Changes in 0.4.1

- The patcher automatically selects the hash-paired **HIR3A** passport; normal **Patch ZDL (no TI)** needs no TI compiler.
- Windows Lite and Standalone contain the same application for their revision. Only HIR3A is shipped as the runtime template.
- **K-weighted, K + band, K + Pink and K + Pink + band** normalization are available. These weight the IR response; this is not a gated LUFS meter.
- Preparation defaults can be saved, loaded and restored after restart. Failed saves no longer report success.
- Empty authoring banks open correctly; empty exports remain rejected before writing output.
- Zoom WAV import uses current preparation settings, including restored defaults.
- Portable banks retain original audio without silently changing saved fitted models.
- Public packaging includes passport/preparation modules and installer helpers, and supports a standalone repository or the development subdirectory.

### Mac preview: validation and limitations

The attached application ZIPs are the unchanged builds tested on native Apple Silicon and Intel **macOS 15.7.9**. Tests covered native startup, GUI, data round trips, K-weighted modes, saved defaults, FIR training and HIR3A export. The maintainer additionally confirmed startup of a preview build, not manual testing of both architectures. Audible playback, prolonged hands-on use and physical pedal installation are separate checks.

### Установка и обновление

**Windows:** полностью распакуйте ZIP и запустите `Install_HYBRIDIR.cmd`. Для обычной работы компиляцию TI включать не нужно. Запускайте `Start_HYBRIDIR.cmd` из установленной папки. Перед обновлением закройте приложение, используйте тот же вариант и канал, сохраняйте резервные копии. Это ZIP с мастером установки, не подписанный EXE/MSI.

**macOS:** распакуйте подходящий ZIP штатной Утилитой архивирования, перенесите `HYBRID IR.app` в «Программы» и откройте. Python, Tcl/Tk и библиотеки включены; отдельные Python и Homebrew не нужны. Для обновления закройте приложение, сохраните данные и замените весь `.app`. Для удаления уберите `.app`; личные данные и настройки сохранятся.

Не отключайте Gatekeeper целиком и не обходите предупреждения о вредоносном ПО или повреждении. Проверка карантина скачанного файла не входила в CI. ### Изменения в 0.4.1

- Патчер автоматически выбирает паспорт **HIR3A** с проверкой суммы; обычный **Patch ZDL (no TI)** не требует компилятора TI.
- Windows Lite и Standalone содержат одинаковое приложение для своей ревизии. Рабочим шаблоном поставляется только HIR3A.
- Доступны **K-weighted, K + band, K + Pink и K + Pink + band**. Это взвешивание отклика IR, не LUFS-метр с гейтингом.
- Настройки подготовки сохраняются как defaults, загружаются вручную и восстанавливаются после перезапуска. При ошибке записи больше не сообщается об успехе.
- Пустой банк редактирования открывается; экспорт пустого банка по-прежнему отклоняется до записи файлов.
- Импорт Zoom WAV использует текущие настройки подготовки, включая восстановленные defaults.
- Переносимые банки сохраняют исходное аудио, не изменяя скрытно готовые подогнанные модели.
- Публичная поставка включает модули паспортов/подготовки и помощники установщика; упаковка поддерживает отдельный репозиторий и подпапку development.

### Mac preview: проверки и ограничения

Приложены неизменённые ZIP, проверенные на нативных Apple Silicon и Intel с **macOS 15.7.9**. Автотесты охватывали запуск, интерфейс, сохранение/чтение данных, K-weighted, defaults, FIR-обучение и экспорт HIR3A. Автор дополнительно подтвердил запуск одной preview-сборки, а не ручную проверку обеих архитектур. Прослушивание, длительная работа и установка в физическую педаль требуют отдельных проверок.

### Аппаратные проверки и лицензии
