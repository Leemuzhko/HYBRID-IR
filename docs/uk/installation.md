## Windows x64 — який файл завантажити

У [Releases](https://github.com/Leemuzhko/HYBRID-IR/releases) виберіть готовий пакет програми, а не **Source code (zip)** чи **Code → Download ZIP** — це вихідний код.

- **Standalone — рекомендований варіант.** Python 3.14, Tcl/Tk та бібліотеки вже всередині. Окреме встановлення Python та інтернет під час встановлення й звичайної роботи не потрібні.
- **Lite — менший архів для тих, хто має Python.** Потрібен [офіційний Python 3.14 x64 для Windows](https://www.python.org/downloads/windows/) із Tcl/Tk та командою `py`. Інсталятор завантажує закріплені залежності з PyPI у власне середовище `.venv`, не змінюючи глобальні бібліотеки.

Windows Lite та Standalone однієї ревізії містять однаковий код і шаблони; окремо доданий Mac preview зібрано з іншого знімка. Lite менший для завантаження, але після встановлення залежності також займають місце. Розробницькі збірки експериментальні; тест пакування не доводить роботу ZDL на педалі. Для приватного репозиторію потрібен доступ через GitHub.

## Встановлення

1. Повністю розпакуйте ZIP в окрему папку.
2. Запустіть **Install_HYBRIDIR.cmd**, виберіть нову папку встановлення та, за бажанням, ярлик.
3. Для звичайної роботи залиште **Developer: enable TI compilation** вимкненим. Натисніть **Install / Update**.
4. Запускайте **Start_HYBRIDIR.cmd** зі встановленої папки або через ярлик.

Це ZIP із майстром встановлення, а не підписаний EXE/MSI. Standalone запускає вбудований Python без його реєстрації в системі та без зміни PATH. Для доступної папки користувача права адміністратора не потрібні.

Звичайна версія використовує `%LOCALAPPDATA%/HYBRIDIR`, розробницька — `%LOCALAPPDATA%/HYBRIDIR-Development`, з окремими ярликом і налаштуваннями. Папку бібліотеки обираєте ви. IR, банки та проєкти зберігайте окремо від програми й середовища.

## Оновлення

Закрийте програму. Розпакуйте новий архів **поза** встановленою папкою, запустіть його інсталятор, виберіть наявну папку та підтвердьте оновлення. Варіант пакета й канал мають збігатися. Для переходу Lite ↔ Standalone або звичайна ↔ розробницька використовуйте окрему папку.

Спочатку перевіряється нова копія, потім стара папка цілком зберігається поруч як резервна. Особисті файли переносяться; змінений код залишається в резервній копії й не підмішується. Lite створює нові середовища та завантажує залежності; Standalone копіює середовище офлайн. Потрібне додаткове місце. Резервні та підготовлені папки залишаються навмисно — видаляйте їх вручну лише після перевірки програми й власних файлів.

Помилка підготовки не змінює старе встановлення. Пізніша помилка запускає спробу відкату. Якщо залишився `<папка>.update.json`, закрийте всі екземпляри та дотримуйтеся шляхів відновлення з нього: збережіть невдалу копію, поверніть зазначену резервну папку й лише після цього видаляйте журнал. Не стирайте встановлення навмання.

Для старих встановлень без реєстру володіння файлами потрібна нова папка. Якщо Windows не дозволяє перевірити запущені процеси, оновлення може зупинитися. При помилці перевірте `installation.log`, якщо його створено.

## Видалення

**Відома проблема початкового Standalone v0.4.1:** видалення може завершитися помилкою всередині AppData. Виправлення development не включено до наявних Windows ZIP. При помилці збережіть встановлення й власні файли та повідомте точний текст; не видаляйте спільну батьківську папку. Додавання Mac preview не замінювало Windows-пакети.

Закрийте програму та запустіть **Uninstall_HYBRIDIR.cmd** у встановленій папці.

Lite використовує окремо встановлений Python. Standalone копіює перевірене середовище видалення Python/Tk до тимчасової папки, щоб не блокувати власні DLL, і прибирає її після завершення. TI не потрібен.

Видаляються зареєстровані незмінені файли програми та службові файли середовища/кешу. Нові й змінені особисті файли зберігаються, тому папка може залишитися. Власний ярлик видаляється лише якщо його не змінено. Видалення налаштувань — окрема опція. IR, проєкти, банки, експорти, інші версії та резервні копії не видаляються автоматично. Реєстрації у списку встановлених програм Windows поки немає.

Якщо файли зайняті або змінені, прочитайте результат. Не видаляйте батьківську папку з іншими проєктами. Системний Python і TI залишаються доступними іншим програмам.

## Компіляція для розробників

Навчання й **Patch ZDL (no TI)** не потребують TI. Для **Build ZDL** увімкніть Developer і вкажіть TI C6000 CGT 8.5.0.LTS та потрібні власні файли-донори. Їх немає в пакеті. Нове пакування не змінює ZDL і не означає нової апаратної перевірки.

Для встановлення з назвою `APP` журнал має назву `APP.update.json`, резервна папка — `APP.backup-…`. Файл, заданий через `IRBQ_SETTINGS_PATH`, автоматично не видаляється: збережіть або видаліть його окремо.

## macOS 15+ — Apple Silicon та Intel (preview)

Цей розділ стосується попередніх Mac-збірок, доданих до **v0.4.1**, а не Windows-інсталятора. Для Apple Silicon вибирайте **ARM64**, для Intel — **x86_64**. Процесор і версію macOS перевірте в **меню Apple → Про цей Mac**. Старіші версії macOS ця збірка не підтримує.

[Завантажити Apple Silicon (ARM64)](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/HYBRID-IR-0.4.1-macOS-arm64-preview.zip) · [Завантажити Intel (x86_64)](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/HYBRID-IR-0.4.1-macOS-x86_64-preview.zip)

Python 3.14.6, Tcl/Tk 9.0.3 і залежності вже всередині **HYBRID IR.app**. Для звичайної роботи не встановлюйте окремо Python, Homebrew або TI. Окремої Mac Lite-збірки немає; Windows-скрипти `.cmd` і PowerShell тут не використовуються.

### Перевірка та встановлення

1. Завантажте ZIP програми для своєї архітектури та сусідній `.zip.sha256` із того самого релізу. **Source code** — не інсталятор.
2. За потреби перевірте архів до запуску: перейдіть у Терміналі до папки завантаження й виконайте відповідну команду нижче. Має бути **OK**. Збіг суми підтверджує опубліковані байти, але не схвалення Apple чи відсутність шкідливого коду.
3. Відкрийте ZIP у Finder штатною Утилітою архівування. Зберігайте пакет **HYBRID IR.app** цілим, не виймайте з нього окремі файли.
4. Перетягніть **HYBRID IR.app** до **«Програми»** (`/Applications`) або особистої папки `~/Applications`. Для спільної папки Finder може попросити дозвіл.
5. Відкрийте скопійовану програму. Особисті IR, банки й проєкти зберігайте поза `.app`.

```sh
cd ~/Downloads
# Apple Silicon — виконайте лише команду для завантаженого ZIP:
shasum -a 256 -c HYBRID-IR-0.4.1-macOS-arm64-preview.zip.sha256
# Intel:
shasum -a 256 -c HYBRID-IR-0.4.1-macOS-x86_64-preview.zip.sha256
```

### Перший запуск і захист macOS

Preview має **технічний ad-hoc підпис, але не Developer ID і не нотаризацію Apple**. Перший запуск може блокуватися; звичайної гарантії перевірки Apple для цієї збірки немає.

Лише якщо ви довіряєте джерелу й перевірили архів: спробуйте відкрити програму, потім виберіть **System Settings → Privacy & Security → Open Anyway** саме для **HYBRID IR**, якщо система це пропонує, і підтвердьте запуск. Не вимикайте Gatekeeper глобально й не знімайте карантин рекурсивно як звичайний крок встановлення. Якщо система повідомляє про шкідливе ПЗ, пошкоджену програму або сума не збігається, зупиніться й з'ясуйте причину, а не обходьте попередження. На керованому Mac може знадобитися адміністратор. [Актуальна інструкція Apple](https://support.apple.com/uk-ua/102445).

### Перевірка роботи

Відкрийте **Zoom ZDL**, додайте WAV через **Import WAV** і виконайте **Patch ZDL (no TI)** з HIR3A. Трейнер підбирає FIR/BQ-моделі; K-weighted і збереження defaults підготовки включено. Перед експериментами зберігайте початкове аудіо, проєкт і банк. Ефект у педаль завантажуйте через [Zoom Effect Manager](https://zoomeffectmanager.com/en/download/): HYBRID IR не встановлює його на педаль напряму.

Автотести обох архітектур перевіряли запуск, збереження/читання даних, нормалізацію, defaults, FIR-навчання, інтерфейс та експорт HIR3A. Автор також повідомив про запуск однієї preview-збірки; це не ручна перевірка обох архітектур. Прослуховування, тривалу роботу й нові банки/ланцюжки потрібно перевіряти на обладнанні. [Звіт Mac-перевірок](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/MACOS-VALIDATION-0.4.1.json).

### Налаштування, бібліотека та журнали

| Дані | Типовий шлях |
| --- | --- |
| Налаштування й defaults підготовки | `~/Library/Application Support/HYBRID IR/settings.json` |
| Кеш і журнали запуску | `~/Library/Caches/HYBRID IR/` |
| Бібліотека | `~/Documents/HYBRID IR/Library/` |
| Інші проєкти, банки й експорти | Вибрані вами папки |

Відкрийте шлях через **Finder → Go → Go to Folder**. `~` — домашня папка користувача. `IRBQ_SETTINGS_PATH`, якщо задано, змінює розташування налаштувань: збережіть цей файл окремо. Пакет `.app` не призначений для особистих даних.

### Оновлення та повернення попередньої версії

Закрийте HYBRID IR, зробіть резервні копії бібліотеки/проєктів/банків і `settings.json`, збережіть попередній `.app` поза папкою «Програми». Окремо розпакуйте й перевірте нову збірку потрібної архітектури, після чого замініть **весь** `.app` у «Програмах». Не об'єднуйте вміст пакетів і не запускайте Windows-оновлювач. Налаштування й бібліотека залишаються поза пакетом. Оновлення цього preview ручне, без автоматичного відкату Windows-інсталятора.

Запустіть нову версію, перевірте defaults і проєкт. Для повернення закрийте її та відновіть попередній `.app`; якщо змінено формат даних, відновіть також їхню резервну копію. У «Програмах» краще залишати лише одну активну копію.

### Видалення

Закрийте програму та перемістіть **HYBRID IR.app** у Смітник. Бібліотека, IR, проєкти, банки, експорти й налаштування залишаться. Windows-деінсталятор і окреме видалення вбудованого Python не потрібні.

Для необов'язкового скидання налаштувань спочатку збережіть копію `settings.json`, потім перейменуйте чи перемістіть файл при закритій програмі. Кеш можна очистити окремо. Перед видаленням двох папок HYBRID IR у Library перевірте їхній вміст. Не видаляйте цілком `~/Library`, `~/Documents` або бібліотеку IR для видалення програми.

<a id="macos-troubleshooting"></a>
### Якщо щось не працює

- **Неправильна архітектура чи ОС:** потрібна macOS 15+; ARM64 — Apple Silicon, x86_64 — Intel.
- **Лише `.cmd` або Python-файли:** це Windows-пакет чи вихідний код. Виберіть Mac ZIP програми вище.
- **Запуск заблоковано чи програму пошкоджено:** див. розділ захисту; повторно завантажте архів і перевірте суму. Попередження про шкідливе ПЗ не є звичайним запитом дозволу.
- **Відхилено шлях експорту:** виберіть справжню папку з правом запису, не користувацьке символічне посилання. Системні псевдоніми Apple `/var`, `/tmp`, `/etc` обробляються; довільні користувацькі посилання заборонені.
- **Помилка запуску чи налаштувань:** перевірте `~/Library/Caches/HYBRID IR/`; збережіть налаштування перед пробним скиданням. Повідомте процесор, версію macOS, назву ZIP і точну помилку. Не додавайте особисті IR чи дані облікового запису до публічного issue.
