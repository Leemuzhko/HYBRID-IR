# Встановлення, оновлення та видалення

[English](../en/installation.md) · [Русский](../ru/installation.md) · **Українська**

[На головну](../../README.uk.md) · [Підготовка IR та збирання банку](workflow.md) · [Обмеження й технічні подробиці](technical.md)

Раджу почати зі звичайного встановлення. Компіляція TI — додатковий шлях для розробників, а не вимога для завантаження власних імпульсів.

## Завантаження — експериментальний дистрибутив для Windows

[Завантажити Trainer + ZDL Patcher для Windows (ZIP)](https://github.com/Leemuzhko/HYBRID-IR/archive/refs/heads/main.zip)

Архів містить вихідний код, інсталятор `.cmd`, список залежностей і готовий
шаблон HYBRID4. Це **дистрибутив на основі вихідного коду, а не автономний EXE**.
Комерційні імпульсні характеристики кабінетів до нього не входять. Посилання веде
на гілку main, а не на версійний реліз. Зберігайте завантажений архів, щоб
мати змогу відтворити результат саме цієї версії.
Поки репозиторій приватний, для завантаження потрібно ввійти до GitHub через
обліковий запис із доступом до нього. Помилка 404 може означати відсутність доступу.

Фіксований шаблон експериментальний і потребує нової перевірки на педалі.
Цей архів не є релізом із підтвердженою працездатністю на обладнанні.

## Встановлення у Windows

1. Встановіть [офіційний 64-бітний Python 3.14](https://www.python.org/downloads/windows/)
   з **Tcl/Tk** та **Python launcher** (`py`). Якщо Python відсутній,
   `Install_HYBRIDIR.cmd` відкриє сторінку завантаження, але не встановить його сам.
2. Завантажте ZIP за посиланням вище, виберіть **Видобути все** та відкрийте
   розпаковану папку з `Install_HYBRIDIR.cmd`. Не запускайте встановлення з ZIP.
3. Запустіть **Install_HYBRIDIR.cmd** подвійним клацанням і виберіть нову папку
   встановлення. Не вмикайте **Developer: enable TI compilation**: поля TI та
   файлів-донорів з'являються лише в цьому режимі. За бажанням залиште прапорець
   **Create a desktop shortcut** (увімкнений за замовчуванням).
   Натисніть **Install / Update** і дочекайтеся завершення. Для завантаження пакетів Python
   із PyPI потрібен інтернет. Залежності встановлюються в окреме середовище
   програми; самому HYBRID IR права адміністратора не потрібні.
4. Запустіть **Start_HYBRIDIR.cmd** із папки встановленої програми, а не з
   розпакованого архіву. Або скористайтеся ярликом **HYBRID IR** з іконкою педалі
   на робочому столі. Наявний ярлик не перезаписується. Вихідний код і ліцензійні
   повідомлення залишаються доступними в папці встановлення.

У разі помилки перевірте `installation.log` у цільовій папці, якщо його створено.
Невдале нове встановлення повторюйте в **нову папку**. Для наявного встановлення
з реєстром видалення використовуйте оновлення нижче. Перед зміною версії збережіть експортовані
моделі та проєкти банків.

Звичайне встановлення вмикає **Patch ZDL (no TI)** та вимикає **Build ZDL**.
Це інсталятор на Python/Tk, який запускається через `.cmd`, а не підписаний
автономний `.exe`. Дочекайтеся завершення збирання, перш ніж закривати програму.

## Оновлення наявного встановлення

Завантажте й розпакуйте новий пакет **поза** папкою встановленої програми.
Закрийте HYBRID IR, запустіть новий `Install_HYBRIDIR.cmd`, виберіть наявну
папку й натисніть **Install / Update**. Підтвердження показує ідентифікатори
старого/нового пакета та кількість змінених програмних файлів. ID позначає точний
пакет, а не семантичну версію чи цифровий підпис. Під час оновлення зберігаються
наявні режим Developer і налаштування компілятора; поля Developer у майстрі
стосуються лише нового встановлення.

Перевірка старих процесів навмисно обережна: може знадобитися закрити й інші
Python-програми, запущені через `launch.py` або `run.py`. Якщо Windows не дозволяє
перевірку процесів, оновлення зупиняється без заміни встановлення.

Спочатку перевіряється окремо підготовлена версія. Потім усе старе встановлення
зберігається поруч у папці `APP.backup-*`, а за початковим шляхом створюється нове
Python-середовище. Потрібне додаткове місце на диску; залежності встановлюються
двічі, інтернет може знадобитися на обох етапах. Особисті IR, банки, проєкти
та експорти копіюються назад і не записуються до реєстру видалення як файли
програми. Спільні налаштування не змінюються. Змінений вихідний код залишається
в резервній копії, нова версія використовує власний код. Якщо особистий файл
конфліктує з новим програмним шляхом, оновлення відхиляється без перезапису.
Наявний ярлик веде на попередній шлях; змінений ярлик не замінюється.

За звичайної помилки заміни стара папка відновлюється. Якщо відкат заблоковано
або процес чи живлення перервано, сусідній журнал `APP.update.json` містить
шлях резервної копії та інструкцію відновлення. Спочатку закрийте всі процеси
програми й встановлення; збережіть папку нової спроби окремо, поверніть резервну
копію на початковий шлях і видаляйте журнал лише після перевірки відновлення.
Незавершений журнал блокує запуск та операції встановлення/видалення.
Не видаляйте резервну копію лише заради усунення повідомлення про помилку.

Папки резервної копії, підготовки `APP.staging-*` та невдалої спроби `APP.failed-*`
залишаються для перевірки. Вони не очищаються автоматично й не видаляються
деінсталятором. Після перевірки програми та даних їх можна видалити вручну,
вибравши лише вказані папки. Не запускайте стару копію з перейменованої папки:
спочатку відновіть початковий шлях. Встановлення без реєстру, незавершені
встановлення та шляхи з посиланнями потребують нової папки чи ручного відновлення.

## Видалення програми

Запустіть **Uninstall_HYBRIDIR.cmd** із папки встановлення. Він використовує
системний Python 3.14, а не окреме середовище, яке видаляється. Спочатку закрийте
програму, перевірте показану кількість файлів і підтвердьте видалення.
Запис у розділі Windows «Інстальовані програми» поки не створюється.

Деінсталятор видаляє зареєстровані файли програми, її `.venv` і `.test-cache`,
а також створений ним ярлик, якщо його не змінено. Нові особисті файли та змінений
вихідний код зберігаються. Не зберігайте особисті файли всередині службового
середовища й кешу. Якщо збережені файли є, папка встановлення залишиться —
програма повідомить про це. Спільні налаштування мови й теми IRBQ Lab видаляються
лише за окремим прапорцем, вимкненим за замовчуванням. Папки ZEM та експортовані
ефекти поза папкою встановлення не видаляються. Власний шлях `IRBQ_SETTINGS_PATH`
також залишається недоторканим.

Якщо видаленню заважають зайняті файли, закрийте програму та повторіть спробу.
Для старих встановлень без реєстру файлів деінсталятор не підходить: не копіюйте
його туди окремо, оскільки належність файлів невідома. Ручний спосіб:

1. Закрийте HYBRID IR, попередньо дочекавшись завершення навчання чи експорту.
2. Якщо в папці встановлення є ваші WAV, моделі, проєкти банків або готові ZDL,
   перенесіть їх у безпечне місце.
3. Видаліть лише папку, вибрану під час встановлення HYBRID IR. Вона містить
   програму та її окреме Python-середовище `.venv`. Не видаляйте батьківську
   папку з іншими програмами чи документами.
4. Видаліть ярлик **HYBRID IR** на робочому столі, якщо його створювали.
5. За бажанням видаліть `%APPDATA%\IRBQ_Lab\settings.json`, щоб скинути мову
   й тему. Налаштування спільні з іншими встановленнями IRBQ Lab: збережіть їх,
   якщо продовжуєте користуватися одним із них. Змінна `IRBQ_SETTINGS_PATH`,
   якщо її задано вручну, перевизначає цей шлях.

Не видаляйте системний Python чи TI лише заради видалення цієї програми:
їх можуть використовувати інші програми. Не чіпайте папку користувацьких
ефектів Zoom Effect Manager та її ZDL. Видалення програми з комп'ютера
не видаляє ефект, уже встановлений у педалі — керуйте ним окремо через ZEM.

## Додаткове встановлення для розробників

Лише для компіляції встановіть [TI C6000 CGT 8.5.0.LTS](https://www.ti.com/tool/C6000-CGT),
увімкніть Developer і вкажіть папки компілятора та штатних ефектів. Повне
середовище CCS не потрібне. Таке встановлення можна виконати пізніше в новій
папці. Помилки попередніх вимог виявляються до копіювання; помилки після його
початку можуть залишити неповну папку. Журнал створюється, коли починається
встановлення залежностей.

Потрібні власні сумісні версії **LineSel**, **ANA234CH** та **Exciter**.
Еталонні назви: `MS-70CDR_LINESEL.ZDL`, `ANA234CH.ZDL`, `MS-70CDR_EXCITER.ZDL`.
Перейменовані копії приймаються, якщо видобуті байти збігаються; пошук охоплює
підпапки. Інсталятор видобуває три невеликі фрагменти та перевіряє SHA-256.
Підійде й локальна папка з уже видобутими сумісними `.bin`.

Інсталятор не завантажує прошивку, не змінює вихідні файли й не звертається
до педалі. Окремі штатні двійкові фрагменти та TI не входять до комплекту,
але скомпільований шаблон містить успадкований штатний код. Несумісні донори
відхиляються без вгадування зсувів. Правила видобування та хеші наведено
в `hybridir_sdk/sdk/runtime_setup.py`.
