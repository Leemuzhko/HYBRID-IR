## Windows x64 — какой файл скачать

В [Releases](https://github.com/Leemuzhko/HYBRID-IR/releases) выбирайте готовый пакет приложения, а не **Source code (zip)** или **Code → Download ZIP** — это исходники.

- **Standalone — рекомендую большинству пользователей.** Python 3.14, Tcl/Tk и библиотеки уже внутри. Для установки и обычной работы не нужны отдельный Python и интернет.
- **Lite — небольшой архив для тех, у кого есть Python.** Нужен [официальный Python 3.14 x64 для Windows](https://www.python.org/downloads/windows/) с Tcl/Tk и командой `py`. Установщик скачивает закреплённые зависимости из PyPI в собственное окружение `.venv`, не меняя глобальные библиотеки.

Windows Lite и Standalone одной ревизии содержат одинаковые код и шаблоны; отдельно добавленный Mac preview собран из другого снимка. Lite легче при скачивании, но зависимости всё равно займут место после установки. Разработческие сборки экспериментальны; тест упаковки не подтверждает работу ZDL на педали. Для приватного репозитория нужен доступ через GitHub.

## Установка

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите **Install_HYBRIDIR.cmd**, выберите новую папку установки и при желании включите ярлык.
3. Для обычной работы оставьте **Developer: enable TI compilation** выключенным. Нажмите **Install / Update**.
4. Запускайте **Start_HYBRIDIR.cmd** из установленной папки или используйте ярлык.

Это ZIP с мастером установки, а не подписанный EXE/MSI. Standalone запускает встроенный Python напрямую: не регистрирует его в системе и не меняет PATH. Для папки своего пользователя права администратора не нужны.

Обычная версия устанавливается по умолчанию в `%LOCALAPPDATA%/HYBRIDIR`, разработческая — в `%LOCALAPPDATA%/HYBRIDIR-Development`, с отдельными ярлыком и настройками. Папку библиотеки выбираете вы. IR, банки и проекты лучше хранить отдельно от файлов программы и среды.

## Обновление

Закройте программу. Распакуйте новый архив **вне** установленной папки, запустите его установщик, укажите прежнюю папку и подтвердите обновление. Вариант поставки и канал должны совпадать. Для перехода Lite ↔ Standalone или обычная ↔ разработческая используйте отдельную папку.

Сначала проверяется новая копия, затем прежняя папка целиком сохраняется рядом как резервная. Личные файлы переносятся; изменённый код программы остаётся в резервной копии и не подмешивается в новую версию. Lite заново создаёт окружения и скачивает зависимости; Standalone копирует среду офлайн. Нужен запас дискового пространства. Резервные и подготовленные папки сохраняются намеренно — удаляйте их вручную только после проверки новой версии и своих файлов.

Ошибка подготовки не затрагивает старую установку. При более поздней ошибке выполняется попытка отката. Если остался `<папка>.update.json`, закройте все экземпляры и следуйте путям восстановления из него: сохраните неудачную копию, верните указанную резервную папку и лишь затем удаляйте журнал. Не стирайте установку вслепую и не устанавливайте повторно поверх незавершённой.

Для старых установок без реестра владения файлами нужна новая папка. Если Windows не позволяет проверить запущенные процессы, обновление может быть остановлено. При ошибке смотрите `installation.log`, если он создан.

## Удаление

**Известная проблема первоначального Standalone v0.4.1:** удаление может завершиться ошибкой внутри AppData. Исправление из development не включено в существующие Windows ZIP. При ошибке сохраните установку и свои файлы, сообщите точный текст; не удаляйте общую родительскую папку. Добавление Mac preview не заменяло Windows-пакеты.

Закройте приложение и запустите **Uninstall_HYBRIDIR.cmd** в установленной папке.

Lite использует отдельно установленный Python. Standalone копирует проверенную среду удаления Python/Tk во временную папку, чтобы не блокировать собственные DLL, и убирает её после завершения. Компилятор TI не нужен.

Удаляются зарегистрированные неизменённые файлы программы и служебные файлы окружения/кеша. Новые и изменённые личные файлы сохраняются, поэтому папка может остаться. Собственный ярлык удаляется только если не изменён. Удаление настроек — отдельная опция. IR, проекты, банки, экспорты, другие версии и резервные копии обновления автоматически не удаляются. В списке установленных приложений Windows программа пока не регистрируется.

Если файлы заняты или изменены, прочитайте результат удаления. Не удаляйте родительскую папку с другими проектами. Системный Python и TI остаются — они могут быть нужны другим программам.

## Компиляция для разработчиков

Для обучения и **Patch ZDL (no TI)** компилятор TI не нужен. Для **Build ZDL** включите Developer и укажите TI C6000 CGT 8.5.0.LTS и необходимые собственные файлы-доноры. Они не входят в поставку. Новая упаковка не меняет шаблон ZDL и не означает новой аппаратной проверки.

Для установки с именем `APP` журнал называется `APP.update.json`, резервная папка — `APP.backup-…`. Файл, заданный через `IRBQ_SETTINGS_PATH`, автоматически не удаляется: сохраните или удалите его отдельно.

## macOS 15+ — Apple Silicon и Intel (preview)

Этот раздел относится к предварительным Mac-сборкам, добавленным к **v0.4.1**, а не к Windows-установщику. Для Apple Silicon выбирайте **ARM64**, для Intel — **x86_64**. Процессор и версию macOS можно посмотреть в **меню Apple → Об этом Mac**. Более старые версии macOS этой сборкой не поддерживаются.

[Скачать Apple Silicon (ARM64)](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/HYBRID-IR-0.4.1-macOS-arm64-preview.zip) · [Скачать Intel (x86_64)](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/HYBRID-IR-0.4.1-macOS-x86_64-preview.zip)

Python 3.14.6, Tcl/Tk 9.0.3 и необходимые библиотеки уже внутри **HYBRID IR.app**. Для обычной работы не устанавливайте отдельно Python, Homebrew или компилятор TI. Отдельной Mac Lite-сборки нет; Windows-скрипты `.cmd` и PowerShell здесь не используются.

### Проверка и установка

1. Скачайте подходящий ZIP приложения и соседний файл `.zip.sha256` из того же релиза. **Source code** — не установщик программы.
2. При необходимости проверьте архив до запуска. В Терминале перейдите в папку загрузки и выполните подходящую команду ниже. Результат должен быть **OK**. Совпадение суммы подтверждает соответствие опубликованным байтам, но не одобрение Apple и не отсутствие вредоносного кода.
3. Дважды нажмите ZIP в Finder: его распакует штатная Утилита архивирования. Сохраняйте пакет **HYBRID IR.app** целиком, не переносите отдельные файлы из него.
4. Перетащите **HYBRID IR.app** в **«Программы»** (`/Applications`) или личную папку `~/Applications`. Для общей папки «Программы» Finder может запросить разрешение.
5. Откройте скопированное приложение, а не файл внутри пакета. Личные IR, банки и проекты храните отдельно от программы.

```sh
cd ~/Downloads
# Apple Silicon — выполните только команду для скачанного ZIP:
shasum -a 256 -c HYBRID-IR-0.4.1-macOS-arm64-preview.zip.sha256
# Intel:
shasum -a 256 -c HYBRID-IR-0.4.1-macOS-x86_64-preview.zip.sha256
```

### Первый запуск и защита macOS

У preview есть **техническая ad-hoc подпись, но нет Developer ID и нотарификации Apple**. Поэтому первый запуск может блокироваться. Обычной гарантии проверки Apple для этой сборки нет.

Только если вы доверяете источнику и проверили архив: попробуйте открыть приложение, затем выберите **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть (Open Anyway)** именно для **HYBRID IR**, если эта возможность предложена, и подтвердите запуск. Не отключайте Gatekeeper целиком и не снимайте карантин рекурсивно в качестве обычного шага установки. При сообщении о вредоносном ПО, повреждённом приложении или несовпадении суммы остановитесь и разберитесь с причиной, а не обходите предупреждение. На управляемом Mac может потребоваться помощь администратора. [Актуальная инструкция Apple](https://support.apple.com/ru-ru/102445).

### Проверка работы

Откройте **Zoom ZDL**, добавьте WAV через **Import WAV** и выполните **Patch ZDL (no TI)** с шаблоном HIR3A. Трейнер позволяет подбирать FIR/BQ-модели; режимы K-weighted и сохранение настроек подготовки включены. Сохраняйте исходное аудио, проекты и банки перед экспериментами. Для загрузки эффекта в педаль используйте [Zoom Effect Manager](https://zoomeffectmanager.com/ru/download/): HYBRID IR не устанавливает эффекты на педаль напрямую.

Автотесты на обеих архитектурах проверяли запуск, сохранение/загрузку данных, нормализацию, defaults, FIR-обучение, интерфейс и экспорт HIR3A. Автор также сообщил о запуске одной preview-сборки; это не означает ручной проверки обеих архитектур. Прослушивание, длительную работу и новые банки/цепочки нужно проверять на реальном оборудовании. [Отчёт Mac-проверок](https://github.com/Leemuzhko/HYBRID-IR/releases/download/v0.4.1/MACOS-VALIDATION-0.4.1.json).

### Настройки, библиотека и журналы

| Данные | Путь по умолчанию |
| --- | --- |
| Настройки и сохранённые defaults подготовки | `~/Library/Application Support/HYBRID IR/settings.json` |
| Кеш и журналы запуска | `~/Library/Caches/HYBRID IR/` |
| Библиотека | `~/Documents/HYBRID IR/Library/` |
| Другие проекты, банки и экспорты | Выбранные вами папки |

Пути можно открыть через **Finder → Переход → Переход к папке**. `~` обозначает домашнюю папку пользователя. Если задан `IRBQ_SETTINGS_PATH`, настройки находятся по этому адресу: сохраните этот файл отдельно. Внутри `.app` пользовательские данные хранить не нужно.

### Обновление и возврат к прежней версии

Закройте HYBRID IR, сделайте резервную копию библиотеки/проектов/банков и `settings.json`, сохраните прежний `.app` вне папки «Программы». Отдельно распакуйте и проверьте новую сборку для своей архитектуры, затем замените **весь** `.app` в «Программах». Не объединяйте содержимое пакетов и не запускайте Windows-обновлятор. Настройки и библиотека находятся снаружи и сохраняются. В этом preview обновление ручное: автоматического отката, как в Windows-установщике, нет.

Запустите новую версию, проверьте defaults и один проект. Для возврата закройте её и восстановите прежний `.app`; если новая версия меняла форматы данных, верните и резервную копию данных. В «Программах» лучше оставить только одну активную копию, чтобы не запускать не ту версию.

### Удаление

Закройте приложение и перенесите **HYBRID IR.app** в Корзину. Библиотека, IR, проекты, банки, экспорты и настройки останутся. Windows-удалятор и отдельное удаление встроенного Python не нужны.

Для необязательного сброса настроек сначала сохраните копию `settings.json`, затем переименуйте или переместите этот файл при закрытой программе. Кеш тоже можно очистить отдельно. Перед удалением проверьте содержимое двух папок HYBRID IR в Library. Не удаляйте целиком `~/Library`, `~/Documents` или библиотеку IR ради удаления приложения.

<a id="macos-troubleshooting"></a>
### Если что-то не работает

- **Неподходящая архитектура или ОС:** проверьте macOS 15+; ARM64 — Apple Silicon, x86_64 — Intel.
- **В архиве только `.cmd` или Python-исходники:** это Windows-версия или исходный пакет. Скачайте Mac ZIP приложения выше.
- **Запуск заблокирован или приложение повреждено:** см. раздел защиты; повторно скачайте файл из релиза и проверьте сумму. Предупреждение о вредоносном ПО не является обычным запросом разрешения.
- **Экспорт отклоняет путь:** выберите настоящую доступную для записи папку, а не пользовательскую символическую ссылку. Системные псевдонимы Apple `/var`, `/tmp` и `/etc` обработаны отдельно; произвольные пользовательские ссылки запрещены.
- **Ошибка запуска или настроек:** посмотрите `~/Library/Caches/HYBRID IR/`; перед пробным сбросом сохраните настройки. В сообщении об ошибке укажите процессор Mac, версию macOS, имя ZIP и точный текст ошибки. Не прикладывайте личные IR и данные аккаунтов к публичному issue.
