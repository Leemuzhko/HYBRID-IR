# Установка, обновление и удаление

[English](../en/installation.md) · **Русский** · [Українська](../uk/installation.md)

## Какой файл скачать

В [Releases](https://github.com/Leemuzhko/HYBRID-IR/releases) выбирайте готовый пакет приложения, а не **Source code (zip)** или **Code → Download ZIP** — это исходники.

- **Standalone — рекомендую большинству пользователей.** Python 3.14, Tcl/Tk и библиотеки уже внутри. Для установки и обычной работы не нужны отдельный Python и интернет.
- **Lite — небольшой архив для тех, у кого есть Python.** Нужен [официальный Python 3.14 x64 для Windows](https://www.python.org/downloads/windows/) с Tcl/Tk и командой `py`. Установщик скачивает закреплённые зависимости из PyPI в собственное окружение `.venv`, не меняя глобальные библиотеки.

В пределах одной версии код приложения и шаблоны одинаковы. Lite легче при скачивании, но зависимости всё равно займут место после установки. Разработческие сборки экспериментальны; тест упаковки не подтверждает работу ZDL на педали. Для приватного репозитория нужен доступ через GitHub.

## Установка

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите **Install_HYBRIDIR.cmd**, выберите новую папку установки и при желании включите ярлык.
3. Для обычной работы оставьте **Developer: enable TI compilation** выключенным. Нажмите **Install / Update**.
4. Запускайте **Start_HYBRIDIR.cmd** из установленной папки или используйте ярлык.

Это ZIP с мастером установки, а не подписанный EXE/MSI. Standalone запускает встроенный Python напрямую: не регистрирует его в системе и не меняет PATH. Для папки своего пользователя права администратора не нужны.

Обычная версия устанавливается по умолчанию в `%LOCALAPPDATA%/HYBRIDIR`, разработческая — в `%LOCALAPPDATA%/HYBRIDIR-Development`, с отдельными ярлыком и настройками. Папку библиотеки выбираете вы. IR, банки и проекты лучше хранить отдельно от файлов программы и среды.

## Обновление

Закройте программу. Распакуйте новый архив **вне** установленной папки, запустите его установщик, укажите прежнюю папку и подтвердите обновление. Вариант поставки и канал должны совпадать. Для перехода Lite ↔ Standalone или обычная ↔ разработческая используйте отдельную папку.

Сначала проверяется новая копия, затем прежняя папка целиком сохраняется рядом как резервная. Личные файлы переносятся; изменённый код программы остаётся в резервной копии и не подмешивается в новую версию. Lite заново создаёт окружения и скачивает зависимости; Standalone копирует среду офлайн. Нужен запас дискового пространства. Резервные и подготовленные папки сохраняются намеренно — удаляйте их вручную только после проверки новой версии и своих файлов.

Ошибка подготовки не затрагивает старую установку. При более поздней ошибке выполняется попытка отката. Если остался `<папка>.update.json`, закройте все экземпляры и следуйте путям восстановления из него: сохраните неудачную копию, верните указанную резервную папку и лишь затем удаляйте журнал. Не стирайте установку вслепую и не устанавливайте повторно поверх незавершённой.

Для старых установок без реестра владения файлами нужна новая папка. Если Windows не позволяет проверить запущенные процессы, обновление может быть остановлено. При ошибке смотрите `installation.log`, если он создан.

## Удаление

Закройте приложение и запустите **Uninstall_HYBRIDIR.cmd** в установленной папке.

Lite использует отдельно установленный Python. Standalone копирует проверенную среду удаления Python/Tk во временную папку, чтобы не блокировать собственные DLL, и убирает её после завершения. Компилятор TI не нужен.

Удаляются зарегистрированные неизменённые файлы программы и служебные файлы окружения/кеша. Новые и изменённые личные файлы сохраняются, поэтому папка может остаться. Собственный ярлык удаляется только если не изменён. Удаление настроек — отдельная опция. IR, проекты, банки, экспорты, другие версии и резервные копии обновления автоматически не удаляются. В списке установленных приложений Windows программа пока не регистрируется.

Если файлы заняты или изменены, прочитайте результат удаления. Не удаляйте родительскую папку с другими проектами. Системный Python и TI остаются — они могут быть нужны другим программам.

## Компиляция для разработчиков

Для обучения и **Patch ZDL (no TI)** компилятор TI не нужен. Для **Build ZDL** включите Developer и укажите TI C6000 CGT 8.5.0.LTS и необходимые собственные файлы-доноры. Они не входят в поставку. Новая упаковка не меняет шаблон ZDL и не означает новой аппаратной проверки.

Для установки с именем `APP` журнал называется `APP.update.json`, резервная папка — `APP.backup-…`. Файл, заданный через `IRBQ_SETTINGS_PATH`, автоматически не удаляется: сохраните или удалите его отдельно.
