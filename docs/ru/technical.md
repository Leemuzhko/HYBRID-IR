# Ограничения и технические детали

[English](../en/technical.md) · [Русский](../ru/technical.md) · [Українська](../uk/technical.md)


Для **Patch ZDL (no TI) автоматически выбран HIR3A**. Работа исходного
синтетического шаблона, сохранение регуляторов и результаты патчера подтверждены
пользователем на MS-70CDR. Каждый новый банк всё равно проверяйте на педали.
В установочные пакеты входят только HIR3A и его паспорт с контрольной суммой.

Есть **K-weighted нормализация**: отдельно, с диапазоном 80–8000 Hz,
с Pink или одновременно с Pink и диапазоном. Это частотное взвешивание
отклика IR, а не LUFS-метр с гейтингом. Прежние режимы сохранены;
экспорт не нормализует сохранённую модель скрытно.

Кнопка **Сохранить как default** на вкладке подготовки запоминает её настройки,
включая нормализацию. **Загрузить default** восстанавливает их; при следующем
запуске они восстанавливаются автоматически. Это настройки подготовки,
а не именованные профили и не набор параметров оптимизатора обучения.

Переносимые проекты и банки сохраняют исходное аудио для явной повторной
подготовки. Старые проекты с одной моделью читаются. Сохраняйте резервные копии:
предыдущие версии программы могут не открыть новые форматы с исходным аудио.

Шаблон допускает **1–8 IR + OFF**, FIR **32–4096 taps**, до **32 BQ на запись**,
включая RESO/PRES. Общий бюджет важнее максимума одного параметра:
код 16 800 B, константы до 12 104 B, включая префикс 1 672 B.
Два независимых IR по 4096 taps в этот профиль **не помещаются**.
Для названий слотов используйте до 5 видимых символов.
Подробнее — [техническое руководство](workflow.md).

DSP cost **20** — не процент загрузки. Два длинных IR вместе с усилителем
могут перегрузить педаль. Уменьшите длину или используйте L/R и проверяйте
всю цепочку на слух. IR OFF не отключает всю обработку ветви.
Это кабинетная фильтрация, не модель усилителя или перегруза.


## HIR3A

| Параметр | Значение |
| --- | ---: |
| `.text` | 16 800 B |
| Бюджет `.const` | 12 104 B |
| Префикс констант | 1 672 B |
| Банк, включая его метаданные | 10 432 B |
| Код + константы | 28 904 B |
| `.fardata` | 144 B |
| Карточка | 128×64, чёрно-белая, до 848 байт RLE |
| Иконка Zoom Effect Manager | 128×96 RGBA |

Паспорт закрепляет SHA256 исходного ZDL:
`14f605e66ea0ca24a1bd0b0873cb15b8dbaf900290ffe78f9f6cb60c99b0f9d4`.
Это консервативные ограничения хранения для конкретного шаблона, не универсальные
пределы железа и не измерение времени обработки. Обычный патчер использует готовый
бинарник, поэтому TI-компилятор не нужен. Версия прошивки и хеш установленного
файла в пользовательском тесте HIR3A независимо не считывались.

Действующий SDK-линкер содержит ограниченное исправление межсекционных
SHT_REL/PCR_S21 переходов. Оно не доказывает корректность любых релокаций C6000.
HIR3A сохраняет приватные T7-обработчики; неработавшие общие compact handlers
не используются.

Изменение банка, имени, ID или карточки не пересобирает DSP-код. Проверки паспорта,
ID и транзакционная запись результатов сохранены. Используйте только доверенные
шаблоны: SHA256 проверяет соответствие пары, а не её подлинность или безопасность.
Исходный UNIT-банк синтетический, это не коммерческий кабинетный IR.

Для host-проверок из корня исходников запустите
`python -B scripts/run_development_tests.py`. GUI-тестам нужны Tk и рабочий стол;
установку и удаление проверяйте на Windows. Необязательные TI-тесты и проверки
с приватными исходными данными отмечаются отдельно, а не засчитываются как PASS.
Манифесты и контрольные суммы проверяют целостность, но не подлинность.
