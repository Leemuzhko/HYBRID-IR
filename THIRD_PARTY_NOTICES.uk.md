## ZoomMultistompZDL — repeat98 та учасники

Першоджерело: https://github.com/repeat98/ZoomMultistompZDL

Зафіксована версія: `4ec75eea32971f4cb7c76d96e2020908888dbfc2`.
README прямо заявляє MIT для коду репозиторію, якщо у файлі не зазначено інше:
https://github.com/repeat98/ZoomMultistompZDL/blob/4ec75eea32971f4cb7c76d96e2020908888dbfc2/README.md#license

Включені похідні компоненти:

- `hybridir_sdk/build/linker.py`: спеціалізований статичний лінкер, локально
  розширений для дослідженого ABI регуляторів/стану та HYBRID IR. Заголовок
  upstream посилається на попередню реалізацію `airwindowsZoom`; окремий
  репозиторій v1 не встановлено, тому перевірена атрибуція стосується зазначеної
  зафіксованої версії upstream.
- `hybridir_sdk/build/screen_image.py`: полотно/RLE-кодувальник із локальними
  змінами відображення регуляторів та виправленнями довгих послідовностей RLE.
- `hybridir_sdk/build/zdl.py`: читання/запис контейнера; текст збігається із
  зафіксованим upstream за порівняння без урахування закінчень рядків.

Upstream містить декларацію MIT у README без окремого файлу LICENSE.
`licenses/ZoomMultistompZDL-MIT.txt` зберігає цю декларацію, атрибуцію автора
та стандартний текст дозволів MIT. Рік авторського права чи оригінальне
повідомлення, яких немає в upstream, не вигадувалися.

## Код проєкту, створений під час дослідження

`sdk/build_effect.py`, `sdk/include/zoom_sdk.h`, `sdk/include/zoom_materialize_init.h`
і `build/zdl_smoke.py` додано до дослідницького репозиторію користувача в коміті
`f4030cf` (Leemuzhko); `build/toolchain.py` — у `bcf94ad`. Це код проєкту, а не
офіційний SDK TI чи Zoom. Trainer, засоби створення банків, ефект/ядро HYBRID IR
та код встановлення є кодом проєкту. Наявну атрибуцію програми збережено
в `irbq_lab/LICENSE.txt`. Графіку картки надав автор проєкту. Рівняння фільтрів
посилаються на W3C Audio EQ Cookbook: https://www.w3.org/TR/audio-eq-cookbook/

## Компоненти, що встановлюються окремо

Python і залежності pip зберігають власні ліцензії у своїх встановленнях.
Цей інсталятор завантажує пакети Python в окреме середовище, а не розповсюджує
їхні встановлені двійкові файли. TI C6000 CGT отримують окремо від Texas Instruments:
https://www.ti.com/tool/C6000-CGT

Три окремі фрагменти середовища виконання (`linesel_handlers.bin`, `divf_rts.bin`,
`c6xabi_attributes.bin`) готуються локально із сумісних файлів користувача,
перевіряються за відомими хешами та не входять до цього дистрибутива як окремі
двійкові файли. Їхні еталонні донори — відповідно LineSel, ANA234CH та Exciter.

Успадкований `hybridir_sdk/build/linker.py` також містить `_DLL_WORDS` —
200-байтовий шаблон вхідної функції, прямо описаний upstream як копія з NoiseGate.
Він включений як числовий масив; під час компонування змінюються кількість
дескрипторів та адреси. Це матеріал, похідний від штатного коду та вбудований
у вихідний текст, а не незалежно написаний код проєкту. Атрибуція ґрунтується
на коментарі/історії upstream, а не на новому побайтовому порівнянні з NoiseGate.

Прошивки Zoom, штатні ефекти, похідний штатний код і сторонні довідкові матеріали
залишаються власністю відповідних правовласників. Вони використовуються для
дослідження сумісності та зворотного проєктування з урахуванням розмежування
